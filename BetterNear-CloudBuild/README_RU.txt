BETTER NEAR — СБОРКА В ОБЛАКЕ (БЕЗ УСТАНОВКИ JAVA НА ПК)

Это ИСХОДНЫЙ ПРОЕКТ, а не готовый .jar. Он содержит GitHub Actions workflow, который пытается собрать мод на сервере GitHub.

ВАЖНО: компиляция ещё не проверена. Если проект содержит несовместимость API, сборка может завершиться ошибкой. Не устанавливай никакие неизвестные .jar.

КАК ПОЛУЧИТЬ .JAR ЧЕРЕЗ БРАУЗЕР:
1. На github.com войди в свой аккаунт (или создай аккаунт с помощью родителя, если нужно).
2. Создай новый репозиторий, например BetterNear. Для простоты можно выбрать Public, чтобы GitHub Actions был доступен без ограничений.
3. Распакуй этот ZIP на компьютере.
4. На странице репозитория нажми Add file -> Upload files.
5. Загрузи ВСЁ содержимое папки BetterNear-CloudBuild, включая скрытую папку .github. Если веб-загрузка не показывает .github, нужно создать workflow через сайт отдельно; иначе автоматическая сборка не запустится.
6. Нажми Commit changes.
7. Открой вкладку Actions и выбери Build Better Near. Если workflow не запустился сам, нажми Run workflow.
8. Дождись зелёной галочки. Открой завершённый запуск и скачай артефакт BetterNear-jar.
9. В скачанном артефакте найди bettern...jar (файл .jar) и скопируй его в .minecraft/mods рядом с Fabric API для Minecraft 1.21.11.

Если сборка красная/failed, это означает ошибку проекта; пришли лог, и его надо будет исправить. Не отключай Windows Defender и не запускай неизвестные файлы.
