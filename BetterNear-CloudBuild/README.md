# Better Near — cloud build

Fabric client mod project for Minecraft Java 1.21.11. This is source code, not a precompiled JAR. GitHub Actions attempts to compile it on a hosted runner using Java 21, so Java does not need to be installed on your computer.

See `README_RU.txt` for the beginner-friendly Russian instructions. Compilation/API compatibility has not been verified; if the workflow fails, its log will show the error to fix.
